Submit Recipe 

El proyecto consiste en el desarrollo de una aplicacion web para compartir recetas de cocina, donde los usuarios podrán registrarse, iniciar sesión, explorar recetas publicadas por otros usuarios y compartir sus propias preparaciones.  

Cada usuario contará con una cuenta protegida mediante nombre de usuario y contraseña. Una vez autenticado, podrá acceder a las diferentes funcionalidades de la plataforma.

Las recetas publicadas incluirán la siguiente información:

+ Título de la receta.
+ Descripción breve del plato.
+ Lista de ingredientes necesarios.
+ Pasos o instrucciones para realizar la preparación.
+ Imagen del resultado final.
+ Usuario que publicó la receta.
+ Fecha de publicación.
+ Comentarios realizados por otros usuarios, cuando existan.

La aplicación permitirá a los usuarios:

• Registrarse creando una cuenta.
• Iniciar y cerrar sesión.
• Visualizar todas las recetas disponibles.
• Consultar el detalle de una receta, incluyendo ingredientes, pasos, imagen y autor.
• Publicar nuevas recetas.
• Editar o eliminar sus propias recetas.
• Agregar comentarios a recetas de otros usuarios.
• Visualizar los comentarios realizados en cada receta.
• Buscar recetas por nombre o por algún criterio básico.
• Acceder a un perfil o sección personal donde puedan visualizarse las recetas publicadas por cada usuario.
