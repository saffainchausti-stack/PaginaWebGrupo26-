Ejecutar comando "make test" para:

Generar sqlc  
Levantar el docker  
Hacer tests  
Bajar el docker  

Para compilar, ejecutar y probar este proyecto es necesario contar con:

Go (versión 1.22 o superior): [https://go.dev/](https://go.dev/)  
Docker y Docker Compose: [https://www.docker.com/](https://www.docker.com/)  
sqlc: [https://docs.sqlc.dev/en/latest/overview/install.html](https://docs.sqlc.dev/en/latest/overview/install.html)
(Instalable mediante: go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest)
Make (incluido por defecto en sistemas Linux/macOS o mediante WSL/Git Bash en Windows).
